# Doacoes-IFPR
 Trabalho Final Semestral | TADS3 - Programação Web
O Doações IFPR é um sistema web desenvolvido como projeto acadêmico para o curso de Tecnologia em Análise e Desenvolvimento de Sistemas (TADS) do IFPR - Campus Telêmaco Borba. O objetivo principal da plataforma é otimizar a logística de doações solidárias dentro da comunidade acadêmica, conectando doadores, beneficiários e voluntários de forma organizada e rastreável.

O sistema permite que doadores cadastrem itens, beneficiários solicitem o resgate e voluntários gerenciem a logística de entrega, garantindo transparência e eficiência no processo.
